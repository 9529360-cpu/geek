# 群发差异审计与进度（2026-08-14）

## 原版挖掘结论（HelloWorld/Pragmaz `Vi()`）
原版群发不是单纯“选聊天+发文本”，能力包括：
- 定时日期（可多日期）
- 保存消息模板
- 文本/图片/视频/文件/音频/电子名片
- `%sa` 问候语、`%nc` 联系人/群组名称、`%nr` 对方真实昵称
- 多版本/变量消息
- 按联系人/群组、粘贴号码、Excel/CSV、群成员私聊、标签、排除联系人、排除群组、全部联系人、全部群组、全部
- 发送间隔、暂停/继续/停止、失败名单导出
- 原版还有按钮消息、漏斗/自动流程、PIX 等扩展功能

## 本次确认的极客落差（已修复）
- `%nr` 只有 UI 无发送替换；现在发送链路支持 `%nr`（无真实昵称时回退聊天名称）。
- 正常消息的换行必须作为一条完整正文保留；已修复旧逻辑把多行拆开随机发送、造成话术不完整的问题。只有显式 `{版本A|版本B}` 才随机展开。
- 已保存消息改为原版内联标签：保存后直接显示消息标签，点击恢复完整正文，标签内 `×` 删除；同名保存会覆盖更新，避免重复模板。
- “创建多版本”只插入 `{A|B|C}`，之前发送不解析；现在每个目标随机展开花括号版本。
- `%sa` 原版变量缺失；现在支持并按当前时段替换为早上好/下午好/晚上好，UI 已补插入按钮。
- 多选附件主进程实际只允许一个文件、WA 发送只取第一个；现在文件选择支持多选，WA 逐个发送全部附件，最后一个带文字 caption。
- 电子名片原来有两处假接线：联系人列表依赖空的 `chat.name`，发送引用不存在的 `whatsapp.Store.Contact` 和 `getMe()`；现已改为 `ContactStore + UserPrefs LID`。无外发构造测试成功生成标准 `BEGIN:VCARD` 消息。
- XLSX 界面是假支持：主进程只允许 CSV/TXT、renderer 按文本读；现在加入 `xlsx` 依赖，主进程解析 XLS/XLSX 第一张表并传 rows，CSV/TXT 仍支持。
- “所有联系人/所有群组/全部”切换不清空旧选择；现在模式切换先清空，避免串入前一模式目标。
- 粘贴号码/Excel 未匹配项直接用裸号码当 chatId；WA 现在用 `W.contact.queryExists` 核验并转换规范 JID，未注册号码被过滤。
- 原版“向群组成员私聊发送”缺失；现在新增真实模式：选择群组→提取成员→去重/排除自己→逐个私聊，不发到群里。
- 群发@全体参数用了错误的 `mentionedJidList`；已改为 WPP 4.3 实际识别的 `mentionedList`。
- 定时任务只存在内存，重启丢失；现在写入 `localStorage.scheduleTasks`，重开群发窗口会重新挂载未来任务。

## 群组标签已按原版语义对齐
- 群组标签只保存 `@g.us` 群组 ID，不再把联系人混入“群组标签”。
- 点击标签是整体替换当前选择，不是追加。
- 点击标签后列表直接筛选为这批群，避免用户还要从全部聊天里找。
- 选择“全部群组（清除筛选）”恢复完整群组列表。
- 同名标签在当前账号下覆盖更新，不产生重复标签。
- 新标签记录账号 ID，账号之间隔离；旧版本无账号字段的数据保留兼容读取。
- 支持删除标签，删除标签不会删除真实 WhatsApp 群。
