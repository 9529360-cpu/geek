# 群发组件一比一审计（2026-08-14）

## 复刻边界

以 HelloWorld/Pragmaz `Vi()` 的 UI、控件层级、显示/隐藏条件、保存与选择语义为准；最终 WhatsApp 发送调用保留当前 WPP 适配器。不能用“有一个同名按钮”代替原版行为。

## 原版 Vi() 组件清单

### 发送设置
- `settings-checkmsgprog` + `multiple-datepicker`：定时开关与多日期选择。
- `range_04`：原版发送间隔 Ion.RangeSlider。
- 原版内容少时由 Alertify 对话框自适应，不强制撑满。

### 消息内容
- `divmsgsalvas` / `msgsalvasdiv` / `salvarmensagem`：已保存消息折叠区 + 小保存 badge。
- `textarea22`：正文。
- `saudacao1` / `nomecontato1` / `nomereal1` / `infovariantes`：变量与多版本 badge。
- `settings-check27761` / `msgautoarquivo` / `imagemsgauto`：Dropzone 附件。
- `addmsgtexto`：追加文字消息。
- `addmsgpix`：PIX 扩展。
- `addmsgvcard` / `settings-checkvcard` / `vcardselect` / `selectvcard`：可搜索 Selectize 名片。
- `settings-checkbuttons` / `selectbuttons`：按钮消息扩展。
- `settings-checkfunil` / `selectfunil`：漏斗扩展，原版默认隐藏。
- `settings-checkmenciona`：@全体。

### 发送目标
- `customRadio1` / `selectcontatos` / `contatosalvosdiv` / `salvarcontatos`：联系人/群组 Selectize、小保存 badge、已保存集合标签。
- `customRadio189` / `textareadesc`：粘贴号码。
- `customRadio12` / `listaexcel`：Excel/CSV。
- `customRadio6` / `selectpartgrupos`：群成员私聊。
- `customRadio9` / `selectlabels`：联系人标签。
- `customRadio3` / `selectexcetocontatos`：排除联系人。
- `customRadio4` / `selectexcetogrupos`：排除群组。
- `customRadio5`：全部联系人/群组。
- 原版各模式通过单选切换显示对应区域，未选模式不占空间。

### 发送中
- `enviando`：切换到独立发送中视图。
- `myBar`：Bootstrap striped/animated 进度条。
- `contador2`：倒计时。
- `pausadomsg`、`pausar-envio`、`retomar-envio`、`parar-envio`：暂停/继续/停止。
- `exportaEnviados`：失败/未发送导出。
- 原版没有当前极客额外的“确认向 X 个聊天群发”二次确认。

## 当前极客已对应

- 定时任务、消息保存、正文变量、多版本、附件、名片、@全体。
- Selectize 风格目标选择、粘贴号码、Excel/CSV、群成员私聊、标签模式。
- 群组标签稳定 ID、整体替换、筛选与删除。
- 排除面板、所有目标模式、发送中进度/倒计时/暂停/停止/失败导出。
- 名片搜索；LID 发送前转 PN；已真实收到 `type=vcard` 与 `BEGIN:VCARD`。
- 原版小保存按钮、小标签；低频目标模式折叠；内容区滚动、底栏固定；点击遮罩不关闭；发送前无二次确认。

## 仍需逐项复刻/核验

1. 当前 `range_04` 仍是两个数字输入，不是原版 Ion.RangeSlider 的视觉与交互。
2. 当前排除联系人/排除群组合并成一个排除面板，不是原版两个独立 Selectize 区域。
3. `addmsgtexto`、PIX、按钮消息、漏斗不能只补 UI；必须找到当前 WPP 可验证发送链路后再接，不能做假功能。
4. 当前附件 Dropzone 通过真实 `sendFile` 链路验证，但原生文件选择器仍需桌面文件对话框级回归。
5. 发送中动画已补齐，但需继续与原版 `spinner-grow + progress-lg` 的尺寸和位置做截图级比对。

## 当前原则

先完成原版已有组件的结构/交互/视觉复刻；扩展功能只有在底层真实可用并完成测试后才显示，不用假按钮冒充完成。
