# 群组克隆/编辑——技术挖底记录（2026-08-14）

## 目标
HelloWorld 的「克隆群组」「群组编辑」一比一移植到极客（WA 账号）。

## 挖到的（原版实现）
1. **克隆**：`Uc.createGroup(N.subject, mEandMeLid._serialized)` → 2 秒后 `Uc.getGroupMetadata(gid)` → `WUPE.Wap.setGroupDescription(gid, desc, newId, descId)`（复制简介）→ `WUPE.Wap.sendSetPicture(gid, pic, pic)`（复制头像）
2. **编辑**（改名称/简介/头像）：`WUPE.Wap.setGroupDescription` + `sendSetPicture` + `GroupDesc.setGroupDesc`（WAP 协议层封装）
3. **Uc 模块**：webpack 混淆（n(模块号)），`Uc` 有 createGroup + getGroupMetadata——**无法直接定位到 WA 模块名**
4. **dropzone 另有**：`WAWebCreateGroupAction.createGroup({announce, ephemeralDuration, full, memberAddMode, membershipApprovalMode, parentGroupId, restrict, thumb, title}, t)`——`t` 未确认（投票功能用——不相关）

## 实测（旧版页面 1843）

|---|---|
| `WAWebCreateGroupAction.createGroup(字符串, me)` | undefined（没建） |

| `WAWebWidFactory.createWid` | ✅ 正常（pn/lid 都返回 Wid） |
| UI 路径（新建群组按钮） | 未找到（旧版页面 87 个按钮无匹配——需要更深入找"新聊天→新建群组"菜单路径） |

## 结论
- **直接调 WA 建群 API 在旧版页面（1843）不兼容**（内部报错——类似媒体 API 的版本差异）
- **原版能用** = pragmaz 的 Uc 封装（适配旧版页面 + WAP 协议）——webpack 混淆，直接复刻难
- **可行路径**：
  A. 复刻 pragmaz 的 Uc（需要：pragmaz-core 里 Uc 的完整实现——但 webpack 混淆——除非跑 pragmaz 的 WUPE 环境（SW 问题））
  B. **UI 模拟**（WA 页面点"新聊天→新建群组"→填名→创建——需要先找到 UI 路径——旧版页面结构）
  C. **最新版页面**（官方 web.whatsapp.com——建群 API 可能正常——但媒体 API 又不兼容——两难）
