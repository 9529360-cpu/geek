# 极客翻译网关接口契约

## 客户端调用

客户端只调用远程网关，不保存任何 DeepL、Google、Azure、OpenAI 或其他供应商密钥。

### Endpoint

```http
POST /v1/translate
Content-Type: application/json
X-Geek-Client: 1
```

### Request

```json
{
  "text": "要翻译的文本",
  "source": "auto",
  "target": "it",
  "chatId": "可选：当前聊天稳定 ID"
}
```

### Response 200

```json
{
  "text": "翻译后的文本",
  "source": "zh",
  "target": "it"
}
```

### Error

```json
{
  "error": "错误说明",
  "code": "quota_exceeded"
}
```

## 服务端职责

- 身份认证和租户隔离；
- 套餐、额度和字符数统计；
- provider 路由；
- 供应商 API Key 只放服务端密钥存储；
- DeepL/Google/Azure/兼容大模型适配；
- 超时、重试和限流；
- 默认不记录原文、译文和聊天内容；
- 错误日志脱敏；
- 只记录必要的用量和审计信息。

## Provider 规划

```text
standard   → DeepL/Google/Azure 等标准翻译 API
premium    → 高质量大模型
custom     → 客户自有服务端配置（不把 Key 下发客户端）
```

客户端不感知 provider，只依赖统一 `/v1/translate` 合同。

## 安全约束

- 客户端只允许 HTTPS；本机开发测试允许 `127.0.0.1`；
- 不接受客户端传入供应商名称、模型名或 API Key；
- `chatId` 仅用于上下文/用量归属，服务端不得默认保存聊天正文；
- 生产服务应使用短期会话认证，而不是长期 API Key 写入客户端。
