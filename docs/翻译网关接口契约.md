# 极客翻译网关接口契约

## 调用边界

渲染层和 WhatsApp WebView 只提交文本、语种与聊天上下文，不持有、显示或传递服务 URL。Electron 主进程根据部署配置选择极客翻译服务：

- 开发环境未配置时使用本机测试服务；
- 正式打包版必须通过 `GEEK_TRANSLATION_GATEWAY_URL` 配置 HTTPS 远程服务；
- 未配置远程服务时正式版拒绝翻译，不回退或暴露本机地址；
- DeepL、Google、Azure、OpenAI 等供应商密钥始终只在服务端。

### 服务端 Endpoint（仅主进程可见）

```http
POST /v1/translate
Content-Type: application/json
X-Geek-Client: 1
```

### Request

```json
{
  "text": "要翻译的文本",
  "source": "auto",
  "target": "it",
  "provider": "local",
  "route": "default",
  "chatId": "可选：当前聊天稳定 ID"
}
```

### Response 200

```json
{
  "text": "翻译后的文本",
  "source": "zh",
  "target": "it"
}
```

### Error

```json
{
  "error": "错误说明",
  "code": "quota_exceeded"
}
```

## 服务端职责

- 身份认证和租户隔离；
- 套餐、额度和字符数统计；
- provider 路由；
- 供应商 API Key 只放服务端密钥存储；
- DeepL/Google/Azure/兼容大模型适配；
- 超时、重试和限流；
- 默认不记录原文、译文和聊天内容；
- 错误日志脱敏；
- 只记录必要的用量和审计信息。

## Provider 规划

```text
standard   → DeepL/Google/Azure 等标准翻译 API
premium    → 高质量大模型
custom     → 客户自有服务端配置（不把 Key 下发客户端）
```

客户端不感知 provider，只依赖统一 `/v1/translate` 合同。

## 安全约束

- 正式版主进程只允许 HTTPS；仅未打包开发环境可使用 `127.0.0.1`；
- 服务 URL 不进入 renderer、WebView、localStorage 或翻译请求 payload；
- 客户端的 `provider`/`route` 只是产品线路偏好，服务端决定真实供应商与模型，客户端不能传入供应商密钥或模型名；
- `chatId` 仅用于上下文/用量归属，服务端不得默认保存聊天正文；
- 生产服务应使用短期会话认证，而不是长期 API Key 写入客户端。
