## 关键 API 结论
- `WAWebGroupExitJob.leaveGroup` 旧版页面假成功 → 用 WAP stanza：
  ```js
  const ws = W.whatsapp.websocket;
  const node = new ws.WapNode('action', { type: 'exit', t: String(Date.now()), add: 'true', id: ws.generateId() }, [ new ws.WapNode('group', { jid: gid }) ]);
  ws.sendSmaxStanza(node).catch(()=>{});  // 3s 超时保护
  ```
- `WAWebGroupModifyInfoJob.setGroupSubject/Description` 需 Wid 实例（chat.id 对象，不是字符串）
- `WAWebCreateGroupAction.createGroup` 参数形态 = ({title,...}, 成员Wid数组)——WPP.group.create 封装正确
- `UserPrefs.getMeUser()` 返回 Wid 对象（{server,user,_serialized}），消息 sender 是 lid 格式——指令权限判断用 getMaybeMeLidUser（原版 mEandMeLid 比较）
- `GroupMetadataStore.find()` 返回 Model 本身（不是 {groupMetadata} 包装）
