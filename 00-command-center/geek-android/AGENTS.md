# N-Forge Project Rules

Project: Geek Android

1. Read `00-command-center/PROJECT.json`, `FACTORY_STATE.json`, and the canonical task record before work.
2. Use one task, one owner, one owned path scope, and one branch/worktree.
3. Do not edit another Agent home or accepted delivery.
4. Require producer self-check, department-manager review, and independent quality review.
5. Require reproducible evidence before acceptance.
6. Record blockers, changes, contracts, and gate results in the command center.
7. Do not release while a mandatory gate fails or a P0/P1 defect remains.
8. Use standby instead of creating busywork.
9. Treat every conversation as replaceable; persist durable truth to project files.
10. Build a bounded task context pack and rotate sessions before context saturation.
11. Reserve context for reasoning and tool results; never load the entire repository by default.
12. Update and query local factory memory before broad file reads; verify canonical source only for exact decisions.
13. In autonomous-inception mode, research and resolve discoverable unknowns without asking the user; escalate only the authority and material decisions listed in AUTONOMY_POLICY.json.
